# SkinSync Website

A responsive, educational skin-type website with five clickable modules:
- Normal Skin
- Dry Skin
- Oily Skin
- Combination Skin
- Sensitive Skin

Clicking a card opens more information in a dialog, including common signs and basic care suggestions.

## Files
- `index.html` — website content and structure
- `style.css` — layout and responsive styling
- `script.js` — clickable skin-type details

## Publish with GitHub Pages
1. Create a public GitHub repository named `skinsync`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment and click **Visit site** on the Pages screen.

SkinSync provides general educational information and does not diagnose skin conditions or replace professional advice.
